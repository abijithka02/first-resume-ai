# Your First Resume with AI

## How to use the resume prompt

1. Open [Resume-Prompt.md](Resume-Prompt.md) or the [Wiki page](https://github.com/abijithka02/first-resume-ai/wiki/Resume-Prompt).
2. Copy the text inside the prompt's code block into a new ChatGPT chat.
3. Answer its questions with your real education, skills, projects, and experience. Explain what you personally did in team work.
4. Check the facts ChatGPT summarizes, then review every line of the resume draft. Correct anything you cannot verify or explain in an interview.
5. Once the wording is accurate, ask for LaTeX only if you want it. Check that the LaTeX contains the same approved information.
